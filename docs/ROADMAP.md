## M1 整理层（先做，最快见效，不需要新方块）

- 整理按钮注入所有库存界面；排序方式（类别/名称/索引/数量）
- 锁定槽位、记忆槽位
- 一键存入 / 一键取出（智能判据 + 全部存入）
- 撤销上一次整理
- 联机版：`StashOpPackage` + 服务端执行器 + 校验
- 单测：`StashSorter` 的合并/排序/锁定/差分最小化

## M2 分级箱子

- 5 档箱子方块（木/铜/铁/钻石/观景）+ 方块实体 + 可变行列 UI
- 染色渲染（复用原版箱子贴图 × 档位色调）
- 升级件（原地升级、内容与命名保留、失败提示）
- 合成表（`.cr`）+ 帮助→合成配方 图鉴收录验证

## M3 背包（A 方案：穿戴式）

- 三档背包衣物（`.clo` 条目 + 独立贴图，档位色沿用箱子色）
- 玩家背包账本（世界目录 JSON，含世界身份校验）
- 拖到人物身上穿戴 / 拖出脱下（原版衣物槽即库存槽，白送）
- 衣物界面加"打开背包"入口
- 升级槽 + 第一批升级：拾取、磁铁、过滤、自动存入、自动补货、垃圾、记忆槽位
- 单测：账本生命周期、档位变更时的格数增减、世界身份校验

## M4 存储网络

- 枢纽（沿原版电线聚合容器）+ 增量刷新
- 终端 UI：搜索语法、排序、取放
- 合成终端（配方查询 + 自动抽料）
- 无线终端
- 性能基线：500 容器 / 8000 槽位下终端开启与刷新的帧时间预算

## M5 抽屉

- 四档抽屉（木/铜/铁/钻石，64/256/1024/4096 组），正面显示图标与数量
- 只接受可堆叠物品；破坏时分批掉落
- 容量升级、抽取锁定、虚空升级
- 抽屉接入存储网络

## M6 打磨

- 触屏手势（拖过多格、双击补满）
- 容器命名 + 终端搜索联动
- 容器预览 HUD
- 多语言（zh-CN / en-US 起步）

## v2 候选

- 按需自动合成（Refined Storage / AE2 思路）
- 背包鼓包模型（自定义模型挂骨骼渲染）
- B 方案：可转手的储物袋（实例 ID + 注册表）
- 第二批背包升级（压缩、熔炼、进食、工具替换、套娃）
