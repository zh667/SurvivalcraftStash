## 新增

**分级熔炉** — 铜 / 铁 / 钻石三档，烧得越来越快（2 / 4 / 8 倍）。

- 用升级件对着炉子右键就地升级，炉里的东西原样保留，正在烧也能升。
- **耗燃料和原版一样**：只是等的时间短了，不省煤。
- 合成：上一档的炉子 + 一圈对应材料；升级件是一圈材料 + 中间一块煤
  （箱子升级件中间是木板，一眼能区分）。

**配方浏览器（类 JEI）** — 在任意合成界面点「配方」打开。

- 列出全部物品，支持拼音和英文搜索。
- 点物品看配方；点配方里的材料可以跳进去看它怎么做，有返回键，支持多层。
- 鼠标悬停显示名字（**手机是触屏，没有悬停，只能点**）。
- 缺的材料标红底；冶炼配方的产物下面有火焰标记。
- 「填材料」一键把材料从物品栏 / 行囊 / 存储网络凑进合成格。
  2×2 装不下的配方会明确提示「配方过大」。

**无线合成终端** — 无线终端的升级版，界面右下角多一块 3×3 合成格。

- 材料可以从**整个存储网络 + 物品栏 + 行囊**里凑。
- 合成：无线终端 + 工作台 + 一圈铁。
  **做出来会保留原来那台终端的绑定**，不用重新绑。
- 贴图是黄铜机身 + 绿屏，和普通无线终端（钢灰 + 青屏）分得清。

## 联机注意事项（**请先看这段**）

**这个版本的联机路径没有经过实机测试。** 单人世界和联机主机走的是同一套代码、
已经测透了；但"联机客户端"是**另一条代码路径**，我没有第二台设备去验证它。

具体来说：

- 单人世界在引擎里叫 `WorkType.Local`，所有"我是客户端"的分支**一行都不会执行**。
  所以"单机没问题"对联机不构成任何保证。
- 涉及的功能：**填材料、一键整理、一键存取、无线合成终端的 3×3**。
  这几样在客户端上都是"把计划发给服务端，服务端校验守恒后落地"。
  这条链路本身有防作弊校验（只许重排、不许凭空增减），逻辑上是安全的，
  但没在真实网络环境下跑过。
- 分级熔炉在联机下**不会有火焰粒子、方块也不发光**。这是设计取舍不是 bug：
  原版的火焰认死了原版熔炉的方块编号，我们要是换过去，整个炉子会被原版逻辑
  改回普通熔炉。炉子正面贴图本身画着火，看得出在烧。

**建议**：联机服务器上线前，先在小号 / 测试房里试一遍填材料和合成终端，
确认东西不会丢再开给大家。真出问题请按下面的方式反馈。

## 出问题怎么反馈

Mod 会往 `Game.log` 里写诊断信息，统一前缀 `[Stash诊断]`。反馈时请给三样：

1. **整份 `Game.log`**（不用自己筛，也不用截取）
   - 联机版：游戏目录下的 `Bugs/Game.log`
   - 插件版：`Mods` 同级的日志目录里的 `Game.log`
2. **截图**
3. **一句话说明你当时在干什么**

日志里会记下这些关键动作：进出世界、方块索引、填材料的完整计划（从哪拿、放到哪）、
熔炉升级前后的内容、合成终端取产物时材料有没有被扣。
绝大多数问题靠这些就能直接定位，不用你再复现一遍。

**联机版的日志超过 10 MB 会被游戏直接清空且不留备份**，
所以发现问题请尽早把日志拷出来。
（想连着测好几天的话，设置里把 `LogMode` 改成 1，会按日期分文件。）

日志本身很轻：一小时正常游玩大概几十 KB，不影响性能。
